# Fly's OSC Chat Box v0.9.0

- Renamed application title, KDE launcher, tray text, and documentation.
- Added six built-in themes: Midnight Blue, AMOLED Black, Nord Frost, Forest, Royal Purple, Light.
- New **Settings → Appearance → Application theme** selector with immediate application and automatic persistence.
- Retained `linux-osc-chatbox` as the project directory, `.desktop` filename, and settings location for migration safety.
- After installing the update, run `python3 install-launcher.py --desktop` **once** to refresh the desktop shortcut label.
- Existing status profiles, layouts, music preferences, emoji assets, and OSC settings remain unchanged.
